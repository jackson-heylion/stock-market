# 见微 · A股模拟交易台

无真实交易、无券商密钥的 **A股模拟盘MVP**（默认GitHub Pages纯静态运行，可选本地行情代理）。采用股票模拟盘普遍具备的「虚拟资金、观察列表、持仓与现金、盈亏、成交明细、模拟买卖和交易费用」闭环，并将对话中五只代表股票的启动条件整理成可维护的模型清单。

## 运行与部署

```bash
npm test
npm run check
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

部署：push 到 `main` 触发 `.github/workflows/pages.yml`。在仓库 **Settings → Pages → Build and deployment** 选择 **GitHub Actions**，若尚未启用。理论网址：`https://jackson-heylion.github.io/stock-market/`。由于仓库最初为**私有空仓库**，GitHub Free 不支持私有仓库直接发布 Pages；需要具备 GitHub Pro/Team 等权限，或用户自行将仓库改为 Public（数据均为公开收盘价与模拟交易）。不把未成功部署描述成已上线。

## 模型

`M1` 中船特气：供需错配/产品涨价。`M2` 利通电子：订单/业绩/趋势共振。`M3` 锋龙股份：正式公告控制权重估。`M4` 新华传媒：重大资产重组估值调整。`M5` 华电辽能：政策题材与情绪扩散。

每只候选股有证据核验清单：已确认/待核/不符合。**不是自动股票扫描器，不显示未经回测的胜率或买点概率**。以后接入日线数据时，先验证来源、日期、复权口径和T+1规则。

## 交易规则及当前局限

- 买入和卖出仅支持100股正整数倍；当日新买入证券不得同日卖出（保守锁住该证券的整个当日仓位）。
- 模拟佣金万分之2.5、最低¥5；过户费十万分之一（双向）；卖出印花税万分之五。所有费率仅作为模拟参数，并非券商正式报价。
- 不实现真实撮合、市价滑点、涨跌停不可成交判定、委托排队、分红送股、跨设备账户系统。实时报价来自不保证时效的公开接口，分时/K线仅供参考。历史盘后成交属于**假设以收盘价成交**的模拟建仓，不保证实盘可成交。
- 支持浏览器手动成交、手动改价、导入/导出、初始化、交易校验；**绝不连接真实资金账户**。

## 实时行情、分时与K线（2026-11-20）

页面直接接入**腾讯财经匿名批量报价**，对缺失证券自动使用**东方财富匿名快照**补齐。盘中每3秒尝试刷新，盘后每60秒尝试刷新；浏览器后台标签页暂停请求。报价在内存中用于持仓**动态估值**，不写回历史交易流水，也不修改2026-11-19初始买入成本。返回数据含源名称及行情时间戳，超时/时间戳缺失会标注为过期或未核验；交易所专业实时性不保证。

**行情图表**在侧栏「行情图表」以及观察列表每个股票的「分时 / K线」入口中。分时为东财公开分钟曲线；日/周/月K取东财 `push2his` 历史K线（前复权）绘制，包含成交量及MA5/MA10/MA20。图表接口若失效，**显式报错，不合成虚假数据**。股票停牌与新股长期无数据时也可能没有分时图。

新浪财经不允许GitHub Pages直接跨域访问，不能将其<script>当作可信报价源。本仓库另外提供**可选的匿名Node代理**，让服务器按腾讯→新浪→东财的顺序补齐报价，供有服务器的用户使用：

```bash
node server/quote-proxy.mjs
# 本地开发网页通过 ?proxy=http://localhost:8787 使用该代理
# 正式Pages可使用你自己部署并配置HTTPS的地址：?proxy=https://你的域名
```

该代理不需要账户、API Key或券商身份信息。它没有在GitHub Pages上运行，默认静态站点仍是**腾讯主源+东财兜底**。不得把免费公开接口当成有授权的商业转发行情服务；正常交易受接口数据延迟、网络和交易所交易规则影响。

## 大盘市场与行情中心

侧栏新增「大盘市场」和「行情中心」：
- **大盘市场**：上证指数、深证成指、创业板指、科创50、沪深300实时参考价及涨跌；切换查看指数分时、日/周/月K；当日行业涨幅前列和A股强势股。指数采用交易所区分的 `sh000001` 等代码，避免与同数字深圳个股混淆。
- **行情中心**：沪深A股、沪市、深市、创业板、科创板五种市场范围；涨幅、跌幅、成交额、成交量四种排行；默认读取每榜前50条，并在已加载记录中按名称、代码筛选。点击证券可打开真实分时/K线，未在原8只模拟交易名单的证券只可查行情，**不能模拟成交**。
- 数据来自腾讯财经的指数快照和东方财富公开排名/板块/走势接口。请求时间不等于交易所行情时间，也不保证持续可用、完整覆盖或公开转发授权。
- 「排名接口覆盖证券数」使用返回的 `data.total`，**不能解释为某时点有效交易证券数量**。当无法获取可靠上涨/下跌家数时明确显示“不可得”，严禁用排行前50只推断全市场比例。
- 指数与榜单独立刷新（约35至45秒），个股快照按原来的盘中3秒目标刷新；实际刷新受网络、源端时延、浏览器前后台状态影响。行情中心的筛选/排行变化不修改交易流水或成本。
- 以上公开行情仅供研究，不保证时效或实盘可交易价格，特别是停牌、涨跌停和开盘集合竞价期间。

## 密集行情表视图（参考主流行情终端）

- 成交量接口 `f5` 单位为手，显示时转换为股；金额和市值原始单位为元，显示万元/亿元。

- 关注列表单独保存在 `stock-market-terminal-follows-v1`，初始包含原8只观察股；最近访问单独保存在 `stock-market-terminal-recent-v1`。这两者不修改模拟交易账本，不新增真实或模拟买入。
- 股票查询只接受6位代码；当前页搜索明确不具备全市场股票名称索引。行业板块列表使用东方财富板块定义，不冒充申万行业分类。

## 全站亮 / 暗主题

顶部导航新增亮色／暗色切换按钮，**默认深色**，点击后对资产总览、大盘市场、行情中心、观察列表、策略模型、分时/K线图、交易流水、弹窗全部生效，不再出现白底行情中心嵌在暗色交易台中的情况。

- CSS: `style.css` 保留原深色布局，`theme.css` 统一提供浅色全局覆盖和**行情终端双主题语义色**，深色版沿用品牌深蓝与暖金点缀。
- JS: `theme.js` 管理切换、`aria-pressed`、按钮文案、页面浏览器主题色；设置独立保存在 `stock-market-theme-v1`。本地存储不可用时退回暗色，不触碰任何模拟交易或关注信息。
- 图表网格、坐标、均线配色使用 CSS 主题变量，不额外获取行情数据。表格保持A股**红涨绿跌**，分页、列排序和查看个股行为与主题切换无关。
- 第一次访问默认深色。已经选择亮色的浏览器刷新页面保持亮色。顶部按钮始终可以切回暗色。
