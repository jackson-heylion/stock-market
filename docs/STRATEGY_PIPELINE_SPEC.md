# 全市场策略研究、执行与持续评估 SPEC

状态：待开发（V3 初步规则升级已实现于本次分支；完整流水线尚未实现）。版本：SPEC v1.0。适用 A 股短线和波段模拟账户。目标：可靠、可解释、可复现地识别交易机会，验证相对于旧策略的增量价值；不承诺收益或胜率，不连接真实券商。

## 0. 范围与不变量
- 保留短线浏览器本地账本、波段 GitHub 账本、原交易历史、费用与 T+1、停牌/涨跌停/交易时段检查；旧版本可重放。历史标杆只作研究，禁止自动注入实时候选或基本面。
- 生产规则、数据版本、回测规则分开。新模型初始仅 shadow/review；不得因为新 SPEC 而自动开启未经验证的买入。当前 V3 为保守规则迭代，不代表准确率已提高。
- 七阶段：全市场筛选 → 市场环境判断 → 策略匹配 → 多因子评分 → 交易执行核验 → 历史回测 → 定期评估策略有效性。前五阶段实时/盘后产生信号；后两阶段独立研究与发布审批，回测不能影响同历史时点的信息集。

## 1. 数据底座与全市场筛选 [待开发]
建立 point-in-time A股证券主数据，按交易日保存上市/退市、停复牌、ST、交易板块及历史涨跌停规则、除权除息、成分/概念标签及有效期；明确主板、创业板、科创板及北交所覆盖范围，未支持市场显式排除。不得使用今日成分倒推历史。
- 快照字段：symbol, exchange, tradeDate, asOf, publishedAt, receivedAt, source, revision, adjustment, quality。历史日线/分钟线、成交量/额、换手、指数、涨跌停、行业/概念、公告、财报、历史一致预期/预期替代量及估值。
- 分页获取全量、去重、断点重试、按市场核对应有/实得数量，保存覆盖率和排除原因；每个账户独立资格及流动性筛选，不以预选涨幅/成交额榜冒充全市场。
- 避免前视：历史可用时点必须早于决策，按当时公告版本；交易价格使用真实不复权价格，趋势因子使用时点一致的复权序列；没有授权/可追溯数据不得编造。
- 验收：历史退市股纳入历史证券池；缺页/重复/错日期、节假日、复权断点、停牌、接口限频均有可复现测试；覆盖率未达配置阈值只展示不交易。先建立数据源清单、成本和授权评估。

## 2. 独立市场环境判断 [待开发]
短线：全市场涨跌家数/中位涨跌、涨跌停、炸板率、连板晋级率、昨日涨停和炸板样本当日收益中位数、主线持续性和扩散。状态：主升、轮动、分歧、退潮、风险、未知。日内特征以决策时点可见样本计算。
波段：指数20/60/120日趋势、市场宽度、行业相对强度、产业景气方向、波动及流动性，独立分类趋势、震荡、下行、风险、未知。
- 每个状态输出贡献因素、时间、覆盖、阈值版本。短线退潮不自动等于波段下行。低覆盖/过期→未知，不新增风险。
- 初始仓位上限假设短线70/40/20/10/0%，波段80/60/40/20/0%；分别映射各自状态，经验证再启用。上限限制新增仓位，不假设风险态下可卖出。
- 验收：完整历史状态转移、缺失/陈旧数据、两个账户状态相反时的独立仓位；V3 指数代理不得标记为情绪周期。

## 3. 策略匹配 [待开发]
每个策略定义可用环境、必要数据、硬门槛、可选因子、买入/加仓/退出条件、最大持有期、失效条件及版本。
| 短线模式 | 研究重点 |
|---|---|
| S1 主线平台突破 | 平台压缩、20日高点、相对行业强度、同时间段量能、突破确认 |
| S2 龙头缩量回踩 | 前置趋势、回撤深度、同时间段缩量、重新承接 |
| S3 主线低位首板启动 | 可见催化、低位、同题材扩散、领涨、封板前可成交 |
| S4 分歧修复 | 昨日预期、首阴/炸板/弱转强独立子型、重新承接 |
| S5 龙头接力 | 龙头辨识度、连板与换手、首次分歧、接力收益、退潮禁追 |
| 波段模式 | 研究重点 |
|---|---|
| W1 业绩超预期 | 公告前一致预期与实际差、预测上修、PEAD；无可靠预期则未知或独立代理 |
| W2 供需周期反转 | 库存、产量、价格、供需缺口、利润拐点 |
| W3 产业景气加速 | 行业订单、需求、盈利加速、相对强度 |
| W4 优质成长回调修复 | 基本面未恶化、估值分位、回调后趋势确认 |
| W5 行业龙头趋势 | 份额、盈利质量、估值、60日超额收益、中期趋势 |
至少每模式有正/负/边界历史样本，历史标杆逐时点复核，不满足则换或标记不满足。模型可拒绝匹配；缺必要因子不得开仓。策略冲突确定优先级，单股禁止重复买入，风险退出优先。

## 4. 多因子评分 [待开发]
初始研究权重（非已验证）：短线情绪25、主线25、龙头20、量价承接20、位置10；波段盈利/预期差30、产业景气25、趋势/相对强度20、估值15、质量10。
- 对连续因子使用当时横截面分位/稳健标准化，按交易板、行业或规模中性化的取舍须记录；短线分钟量用历史同一时间段分布，禁止线性代理冒充真实同时间量比。
- 分数、覆盖率、硬门槛、因子贡献、数据时点、排名、拒绝原因分别输出；缺失不设为零或重新归一化掩盖。评分不等于概率；若研究概率需独立校准。
- 阈值、权重、组合与退出规则由训练/验证窗口确定，固定后进入样本外；不反复挑最优回测。V3 条件确认度仅检查清单，不是正式加权评分。
- 验收：因子边界、缺失、量纲、排序稳定性、行业中性化、权重合计、模型冲突及反事实测试。

## 5. 交易执行核验 [待开发扩展；已有基本约束]
信号时点和撮合时点分离；模拟实时或历史都禁止同一根未完成K线的未来值成交。记录订单状态、拒单、未成交/部分成交、费用、滑点、流动性容量、T+1、停牌、价格笼子/涨跌停与板块最小交易单位、交易日历。无盘口数据仅允许明示的保守模拟，不能假定涨停/跌停可成交。
- 每笔成交前重新检查报价身份、价格、时点、策略版本、仓位、现金、同日交易、风险状态；交易批次按退出优先和确定性排名处理，幂等并可重放，防止并发覆盖或重复买入。
- 短线保留人工选中后执行，波段 GitHub 授权执行；研究回测绝不写入任何实际模拟账本。风险/收益参数按账户独立；ATR与结构止损待验证，与既有固定风险上限共同测试。
- 验收：跨日、节假日、涨跌停、停牌、价格滑点、费用、部分成交、重复执行、版本迁移、资金不足及风险状态变更测试；账本快照前后可对账。

## 6. 历史回测 [待开发]
- 使用尽可能完整的2020年至2026年可获交易日数据；缺失区间显式披露。事件驱动与时点回放，短线需分钟级信号；没有历史分时不得以日K伪造盘中买点。波段使用历史公告发布时间、预期版本、财报修订和估值。
- 基准：旧 V2、冻结的 V3、简单指数/行业基准、等风险简化策略；相同交易区间、手续费、滑点、资金、机会集合。各模式单独、组合、市场状态/板块分组。
- 初始划分：2020–2023训练，2024验证，2025及可用2026样本外；如果历史已被用于设计标杆或调参，不能声称独立盲测，保留未来冻结 shadow 期。滚动窗口、间隔/清除重叠标签，参数固定后才测样本外。
- 短线 1/2/3/5日净收益及相对收益、波段10/20/40/60日；输出可成交率、信号频次、胜率及置信区间、盈亏比、期望收益、最大回撤、换手、交易成本、年化/风险调整收益、超额收益、暴露、容量。无足够样本显示不足，失败/退市/未成交全保留；标杆单独标识不做代表性样本。
- 冻结数据 manifest、代码SHA、参数、随机种子（如使用）、订单与每日净值，独立复算。验收：时点泄漏、幸存者偏差、成本敏感性、极端市场、跨模型对照、可重复性；不以胜率单项作为发布条件。

## 7. 定期有效性评估 [待开发，当前不启用定时任务]
每日记录所有候选、分数、通过/拒绝、可成交性和随后成熟的预测周期结果。每周短线、每月波段出独立评估；滚动统计样本量、收益/回撤、信号覆盖、成交率、因子漂移、各环境绩效、相对基准表现及异常。
- 设定预注册发布门槛：成本后超额、风险预算、最少有效独立样本、覆盖、成交可行性；阈值需由研究阶段确定并文档化，不在此伪造实测数。样本不足=未验证；严重数据异常或超风险预算→停止新增策略买入、人工复核；回滚到最近经验证版本，不重写旧历史。
- 研究→shadow→审批→分版本发布；新旧平行评估、失败记录、回滚记录。定期任务只在实现、验收及明确授权后启用；本 SPEC 不创建或更改调度。
